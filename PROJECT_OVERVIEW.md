# Project overview

## Purpose

**Electrical-Engineer** is an Apache-2.0 **undergraduate electrical-engineering lab**: CLI `electrical-engineer`, persistent localhost UI, and stdio MCP. A **capability registry** is the domain contract. Providers check numbers when they exist and otherwise emit the exact token **unchecked**. YAML recipes and the as-built JSON UI are this-pass encodings, not the identity.
