# Microprocessors and microcontrollers — syllabus union

Bound: `docs/curriculum-map.md` (IITR, NITT, AICTE-family, MIT/Berkeley, GATE overlay). NITT B.Tech EEE names microprocessors as a core/applied-electronics subject; this pack is that UG layer.

This pack is the EEE microprocessor elective: 8085 programmer and bus timing, interrupts, then memory/IO interfacing and an 8051 introduction. Depth is coursework (assignment, lab numerical, exam-style), not a product MCU HAL, JTAG debug flow, or an RTOS.

## Units

- `01-8085-architecture-timing` — 8085 architecture, timing, interrupts
- `02-interfacing-8051-intro` — Memory/IO interfacing, 8051 intro

## Outcomes

After this pack a UG EEE student can name 8085 registers and flags; count T-states and machine cycles; use TRAP/RST/INTR vector addresses and SIM/RIM; decode chip-selects; write an 8255 Mode-0 control word; and size 8051 timer reloads and Mode-1 baud rates.
